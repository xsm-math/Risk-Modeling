# 方法与实验边界

## 数据来源

默认由 `src/risk/data.py` 的显式 logistic 数据生成过程生成 8,000 条样本，seed=42。
标签从给定违约概率的伯努利分布抽样，并注入部分缺失值和年龄异常值。
客户编号也是模拟生成，不包含真实客户信息。原始 CSV 不上传，运行时自动生成。

| 字段 | 含义 |
| --- | --- |
| customer_id / is_default | 模拟客户编号 / 违约标签（1=违约） |
| age / monthly_income | 年龄 / 月收入 |
| debt_ratio / utilization | 负债率 / 额度使用率 |
| credit_score | 模拟信用分 |
| delinq_30d_2y / delinq_90d_2y | 近两年 30 天 / 90 天逾期次数 |
| inquiry_6m | 近半年查询次数 |
| credit_history_months | 信用历史月数 |
| loan_amount / employment_years / num_open_accounts | 贷款金额 / 就业年限 / 开立账户数 |

金额单位统一按元解释，仅为模拟口径；没有真实征信定义或观察窗口验证。

## 训练、验证与测试

先应用固定规则清洗并按客户去重，再做两级分层切分：70% 开发集、30% 测试集；开发集的 20% 用于验证。
整数截断后为拟合 4,481 / 验证 1,120 / 测试 2,399。
缺失值中位数、分箱边界、合并规则、WOE、IV 筛选以及标准化参数都只从拟合集学习。
逻辑回归只优化拟合集损失；验证标签仅用于选择成本阈值，测试结果不反向改变本次配置。

**历史选择偏差：**原项目的参数扫描脚本按测试 AUC 选择分箱配置。本次删除该脚本并沿用现有配置，不再继续挑选测试指标。
修复当前流水线不能消除此前接触测试集带来的偏差。这里的指标是可复现的教学基线，未来应使用新数据与独立留出集。

## 公式与实现

- WOE = ln(各箱坏样本占全部坏样本比例 / 各箱好样本占全部好样本比例)，使用平滑避免 log(0)。
- IV = Σ(bad% − good%) × WOE；筛选阈值 0.02 仅为实验配置。
- 逻辑回归目标为平均交叉熵 + 0.5 × L2 × ||w||²，截距不惩罚。
- AUC 用 ROC 梯形积分与平均秩两种方式核对；KS 使用 max(TPR−FPR)。
- 标准化模型还原：w_raw = w_std / σ；b_raw = b_std − μ·w_raw。
- score = 600 − (20/ln 2) × [ln 20 + logit(p)]。高分表示低风险。
- 成本 = FP × 400 + FN × 8,200。验证集在 [0.001, 0.999] 的 199 个阈值中选最小值。
- PSI 同时监控特征与预测分数。收入乘 1.3 是人为分布偏移，不代表真实业务冲击。

## 修复记录

1. 全量样本中位数填充 → 仅拟合集学习中位数。
2. WOE/IV 使用了验证标签 → 仅在拟合集估计。
3. 标准化权重直接导出评分卡 → 还原原始 WOE 系数和截距。
4. PSI 监控模块未实现 → 特征、分数、三级告警与漂移实验。
5. 常量与二值特征漂移可能返回零 → 增加适配边界和回归测试。
6. 重复 fit 保留旧标准化状态 → 每次拟合重置。
