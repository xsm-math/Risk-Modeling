# 数据字典与可用信息

数据：Yeh, I. (2009), UCI Default of Credit Card Clients, DOI 10.24432/C55S3H。
来源许可：CC BY 4.0。下载原始文件不修改，解析与特征生成均在本项目完成。

| 字段 | 解释 | 模型使用 |
|---|---|---|
| ID | 行/客户记录编号，无时间含义 | 仅审计 |
| LIMIT_BAL | 信用额度，新台币；不是实际违约敞口 | 是 |
| SEX / EDUCATION / MARRIAGE / AGE | 人口属性 | 排除 |
| PAY_0, PAY_2, …, PAY_6 | 2005年9月至4月还款状态 | 是 |
| BILL_AMT1…6 | 9月至4月账单金额，新台币，负值保留 | 是 |
| PAY_AMT1…6 | 9月至4月付款金额，新台币 | 是 |
| default payment next month | 下月违约标签，1=违约 | 仅监督标签 |
| utilization_latest | 最新账单/额度 | 固定衍生 |
| utilization_mean | 六期账单均值/额度 | 固定衍生 |
| delayed_months | 六期还款状态≥1的期数 | 固定衍生 |
| max_delay | 六期状态最大值，负值先截为0 | 固定衍生 |
| payment_bill_ratio | 六期付款合计/(六期正账单合计+1) | 固定衍生 |

最后一项只是历史付款与账单的粗略比率，跨月对应关系并不等同于合同还款率。
衍生指标不将额度当作收入，不把数据中不存在的收入、查询次数或贷款金额补造出来。

UCI说明还款状态-1为按时支付、1至9为延迟月数（9含更长延迟）；文件还有-2和0，
其具体业务解释在此引用的元数据中不完整，故保留原码，不能擅自称为缺失或坏客户。
所有特征都来自观察窗口，预测时点设为窗口结束后；没有逐字段入库时间，
因此这仅是研究层面的可用性假设。不同客户没有不同的观测截止日期，不能做真实OOT。

排除人口属性只是本研究的设计选择，金融行为变量仍可能包含代理信息，
不构成公平性或合规认证。已有客户样本也不能代表被拒绝申请者。
